UniSwap Campus Marketplace

A secure, campus-exclusive peer-to-peer exchange platform for college students to trade used textbooks, graphing calculators, lab coats, and electronics with institutional email verification.

Read Course Report Architecture & Permissions

Core Features & Design Highlights

🔒 Campus Domain Gate

Signup is strictly restricted to valid institutional domains stored in the dynamic Campus model. Cryptographically signed email tokens gate browsing, listings, and chats.

📚 Multi-Category Listings

Browse and search items with multi-criteria filters: condition, category, price range, and full-text keyword search, coupled with multi-image formset uploads.

💬 Peer-to-Peer Messaging

Direct campus coordination system with built-in anti-self-messaging rules and comprehensive participant IDOR protection preventing snooping.

🤝 Enforced Deal Lifecycle

A deterministic transaction state machine: Requested → Agreed → Completed. Only the seller can agree, and completion automatically marks items as Sold.

⭐ Verified Seller Reviews

Only parties of a Completed transaction can leave a review. Seller ratings are computed live using database Avg aggregates to guarantee mathematical integrity without denormalization.

🛡️ Zero-IDOR Architecture

Every view fetching conversations, transactions, or reviews filters by the active participant before running get_object_or_404, completely eliminating IDOR vulnerabilities.

Quick Local Setup

# 1. Clone the repository
git clone https://github.com/<username>/<repo-name>.git
cd uniswap

# 2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# 3. Install pinned dependencies
pip install -r requirements.txt

# 4. Configure local environment variables
cp .env.example .env

# 5. Apply database migrations
python manage.py migrate

# 6. Seed categories, campus, and sample listings
python manage.py seed_data

# 7. Run the test suite
python manage.py test

# 8. Start the development server
python manage.py runserver
